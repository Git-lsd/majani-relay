1Plot visit

Relay farmer
  • Consent read aloud (Swahili audio); the visit cannot start without it
  • 15 leaf photos: 3 leaves × 5 trees, with a photo quality check
  • Optional: 3 farm taps and a 6-question checklist (not used by the AI)

2AI check, each photo

Runs in the browser
  • MobileNetV3 backbone (ONNX, 16.8 MB, onnxruntime-web)
  • Small head (82 KB) gives one of:
healthyleaf rustleaf minerbrown eye spotPhomaother problem

3Not-sure gate

Any one of these
  • Confidence below the line
  • Photo unlike the 1,400 stored photos and not close to an officer-labelled one
  • "Other problem" on top
"Not sure — the officer will look"

4Answer

Read or played to the farmer
  • From a fixed list of 24 answers, never free text
  • Swahili text and audio; Kikuyu partly
  • "The extension officer makes the final call." No spray names or doses

7Co-op screen

Co-op office
  • Rust share per village, adjusted for small samples (empirical Bayes)
  • Alert if chance of rust share > 25% is above 0.5
  • Ranked villages; CSV export

5Records on the phone

IndexedDB, no server
  • Member number saved only as a SHA-256 code; no names
  • Photos kept as 160-pixel thumbnails
Back to the farms

The ranking shows where rust was found. The officer visits those villages first; relay farmers keep checking plots, and each check feeds the same loop.

It ranks rust already seen; it does not predict outbreaks.
